02Goal

배경과 데이터를 2~3문장으로 쓰고, 이 프로젝트에서 하려던 것을 글머리표로 정리해 주세요.

Sepsis is one of the leading causes of death in intensive care units, and outcomes depend heavily on how early high-risk patients are identified. Using 데이터 이름 (예: MIMIC-IV), which contains 환자 수 ICU stays, this project asked:

  • 목표 1: 어떤 시점의 데이터로 무엇을 예측하는지
  • 목표 2: 어떤 변수가 위험도에 영향을 주는지
  • 목표 3: 결과를 어떻게 활용할 수 있는지

03Methodology & Summary

  • Data: 데이터 출처, 기간, 사용한 표(테이블)와 대상 환자 기준
  • Preprocessing: 결측치 처리, 시간 구간 설정, 이상치 처리
  • Features: 만든 변수 (활력 징후, 검사 수치 등)
  • Models: 비교한 모델과 기준 모델(baseline)
  • Evaluation: 평가 지표와 검증 방법 (예: AUROC, recall, 5-fold CV)
